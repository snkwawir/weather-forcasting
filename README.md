# Weather Forecasting Data Pipeline

## Overview
This project develops a structured weather forecasting and preprocessing pipeline using meteorological data from Canberra, Australia. The analysis focuses on data cleaning, missing value imputation, feature engineering, categorical normalization, and exploratory statistical analysis to support predictive weather classification workflows.

## Objectives
- Build preprocessing workflows for meteorological datasets
- Develop structured data cleaning and validation pipelines
- Engineer predictive weather classification variables
- Analyze relationships between environmental conditions and rainfall outcomes
- Improve dataset quality for downstream forecasting applications

## Tools & Technologies
- R
- mice
- Statistical Testing
- Data Cleaning
- Feature Engineering
- Exploratory Data Analysis
- Data Validation
- Preprocessing Pipelines

## Key Features
- Designed preprocessing workflows for 240+ observations and 20+ weather variables
- Built missing value imputation and categorical normalization pipelines
- Developed binary rainfall classification features for forecasting analysis
- Applied Fisher tests, T-tests, and exploratory statistical analysis techniques
- Created structured validation workflows for meteorological data quality assessment

## Results
The project successfully transformed raw meteorological datasets into analysis-ready forecasting data while identifying significant relationships between humidity, pressure, and rainfall prediction outcomes through structured preprocessing and statistical analysis workflows.
